# Practica_wordpress
En este trabajo voy a mostrar cómo hice una página web usando WordPress. Con imágenes voy a explicar paso a paso cómo funciona, qué cosas añadí, los plugins que usé y cómo personalicé el diseño para que todo se vea bien y sea fácil de usar. También voy a mostrar un poco cómo se organiza la página y cómo se sube contenido. La idea es que se vea todo el proceso de forma sencilla y que cualquiera pueda entender cómo construí mi web.



En esta imagen podemos ver el inicio de la pagina web, podemos ver diferentes usos, por ejemplo, arriba a la derecha mis redes sociales para contactar conmigo, las diferentes noticias, un buscador funcional.
